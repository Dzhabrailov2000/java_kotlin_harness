# Пилот обвязки Java/Kotlin

Результат - `report.html`. Протокол, зафиксированный до попыток, - `PROTOCOL.md`.
Точное состояние входов и порядок - `experiment.json`; версии окружения - `environment.json`.

Серия завершена: 32 исходные попытки, 30 успешных результатов и 2 клиентских таймаута без готового
решения. 14 завершенных реализаций прошли frozen-тесты, 16 ревью подтверждены независимой сессией
и автором. Прирост качества от обвязки этим пилотом не установлен. Выводы и ограничения - в HTML
и conclusions.json; две дополнительные границы покрытия - в posthoc-findings.json.

## Содержимое

- `snapshot/` - отдельная копия общего слоя на исходном commit; активная установка не меняется.
- `tasks/` - публичный workspace, задание, скрытый verifier, эталон или контрольная мутация.
- `fixture-validation/` - запуски проверки самих заданий, включая неуспешную подготовку.
- `preflight/` - технические пробы клиентов, включая неудачные. Они не входят в 32 оценки.
- `runs/Rxx/` - исходный prompt, команда, CLI-события, запросы/ответы поставщика, файлы результата,
  дифф, независимые тесты и `result.json`. HTTP-заголовки с авторизацией не записываются.
- `blind/` - анонимные пакеты для независимой оценки. Соответствие попыткам в `blind-map.json`
  проверяющим не передается.
- `manual-review.json` - проверенные решения по содержанию ревью.
- `skill-loading.json` - подтверждение содержимого навыков в фактическом контексте модели.
- `reviews/` - независимые проверки заданий, запускателя и результата.
- `posthoc-findings.json` - дополнительные наблюдения, не меняющие замороженные критерии и баллы.
- `transport-observations.json` - завершение отдельных HTTP-ответов и повторы содержимого внутри попытки.
- `credential-scan.json` - ограниченный поиск признаков учетных данных в финальных трассах.
- `NEXT_EXPERIMENT.md` - проект следующей серии; она не запускалась.

В сырых result.json поле skill_catalog_present проверяет появление имени навыка в любом запросе,
поэтому оно не отделяет начальный каталог от позднего чтения файла. HTML использует более точный
пост-анализ: имена в первом запросе и две уникальные строки тела навыка в фактически переданном
контексте. Простой Glob/rg по именам SKILL.md не засчитывается как загрузка содержимого. Этот анализ
не меняет входы попыток, исходные результаты или функциональные оценки.

## Обновить представление сохраненных данных

Из корня репозитория:

```sh
python3 evals/harness-pilot/analyze_skill_loading.py
python3 evals/harness-pilot/analyze_transport.py
python3 evals/harness-pilot/scan_credentials.py
python3 evals/harness-pilot/build_report.py
python3 evals/harness-pilot/verify_report.py
```

Это локальная обработка готовых доказательств, без новых запросов к моделям. HTML содержит основные
результаты, задания, ответы, диффы и протокол; ссылки на сырые данные требуют соседнего каталога.
Проверка браузером не выполнялась: браузерный инструмент отклонил file URL. Проверка HTML статическая.

## Продолжить незавершенную серию

```sh
python3 evals/harness-pilot/run.py
```

Команда выполняет авторизованные CLI-вызовы Claude/Codex и расходует их квоту. Полностью завершенные
попытки пропускаются. Уже начатая попытка без result.json требует явного разбора; запускатель не
перетирает ее и не заменяет лучшей. Перед продолжением проверяются контрольные суммы замороженных
файлов. Пользовательских ограничений времени, ходов и токенов модели не задано.

## Новая версия

Новые задания, исправления навыков и изменения запускателя должны получить новый каталог, манифест
и отдельные результаты. Старый результат нельзя приписать измененным файлам. Перед новым запуском
снова проверяются эталон/мутация, окружение и фактический контекст четырех условий.

Облачные модели могут меняться на стороне поставщика. Здесь воспроизводятся сохраненные команды,
входы, настройки и проверки; полное повторение скрытого серверного состояния модели не гарантируется.
Нативные сетевые повторы CLI, если они происходят, остаются в трассе одной попытки. Дополнительный
запуск агента для выбора более удачного ответа не выполняется.
