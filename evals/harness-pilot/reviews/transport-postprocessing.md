# Проверка постобработки транспортных событий

Подтвержденных critical/major дефектов в проверенном срезе R01-R17 не найдено. Успешный JSON-ответ R17 корректно распознан как завершенный. Его транспортный повтор остается частью одной попытки, не увеличивает число независимых испытаний и не меняет основной балл.

## Что проверено

Прочитаны `analyze_transport.py`, `transport-observations.json`, `transport-events.md`, транспортные дополнения `build_report.py` и `quality-review.json`. Повторно разобраны сохраненные запросы и ответы всех 17 завершенных попыток без запуска моделей. Производные файлы, замороженные входы, runner и raw results не изменялись.

Для каждой попытки повторно построены записи completion, HTTP status, stream/max_tokens и same_context_as. Все записи совпали с transport-observations.json; число model request записей совпало с сохраненным `result.evidence.model_requests`. В проверенном срезе только R17 имеет один ответ без terminal event и одну повторную отправку сопоставленного контекста. R18 в производной отсутствует, что соответствует ее незавершенному состоянию на момент среза.

## R17: завершенный JSON не считается ошибкой

- `0002-response.bin` является SSE-потоком без message_stop или другого terminal event. `inspect_response` возвращает format=stream, completed=false, terminal_events=[].
- `0003-response.bin` содержит обычный JSON с type=message и stop_reason=tool_use. `analyze_transport.py:30-34` возвращает completed=true. Это завершение одного модельного ответа с запросом инструмента, а не самостоятельное утверждение об успешности всей задачи.
- Между `0002-request.json` и `0003-request.json` изменены ровно два поля: stream=true -> false и max_tokens=128000 -> 64000. Остальное содержимое совпало. Исключение этих двух полей при сравнении контекста явно описано в методике и сами их значения сохранены в каждой записи.
- Итог R17 содержит одну попытку, 14 model requests, valid_attempt=true и task_pass=true. Время клиента 875.612 с и клиентские счетчики 601663 входных / 28922 выходных токенов не переписаны постобработкой. Это проверка сохраненного учета, не независимое измерение серверного биллинга.

## Причины, расход и интерпретация

`build_report.py:105-109` прямо объясняет, что повтор является событием внутри исходной попытки, время ожидания сохранено, а весь расход оборванных запросов может отсутствовать в итоговом клиентском usage. Время и токены не приписаны целиком эффекту обвязки. `transport-events.md` не приписывает IncompleteRead конкретной попытке или поставщику без request id и не объявляет исключение HTTP-потока завершением runner. Эти ограничения соответствуют доступным доказательствам.

Отсутствие terminal event доказывает неполноту сохраненного ответа. Само по себе оно не доказывает, на каком участке цепочки закрылось соединение, сколько сервер успел вычислить или что было списано по подписке. Заголовок HTTP 200 не доказывает завершение всего потока.

same_context_resubmissions означает совпадение тела после удаления stream/max_tokens. Это полезная наблюдаемая метрика, но не исчерпывающий детектор всех повторов: изменение любого другого поля даст иной хэш. Нулевой счетчик не следует пересказывать как доказательство отсутствия любых внутренних retry клиента. api_retry незавершенного R18 пока не относится к проверенному производному срезу.

## Качество кода и дополнительный probe

Новые краткие выводы quality-review.json для T02/T04 согласуются с указанными независимыми заключениями: именованные ключи в агрегации требовались обоим условиям, а локальный try-with-resources присутствует во всех четырех Stream-решениях. Размер кода или совпадение с текстом skill не превращены в балл или доказательство преимущества.

Транспортный блок не заменяет и не скрывает отдельный блок о parallel Stream и ограничении эталона. Качественное описание T04 прямо отсылает к этому ограничению. Замороженные основные оценки не корректировались по дополнительному probe.

## Границы заключения

Это проверка производного среза, а не финальная сверка всей серии. Завершенные позднее попытки, полный итоговый HTML, итоговые выводы и полнота реального денежного учета остаются вне ее границ. Сохранен только этот отчет.
