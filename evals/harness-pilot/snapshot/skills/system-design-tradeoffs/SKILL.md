# Системное решение с компромиссом

Форму записи задает проект (шаблон ADR), здесь только ход мысли. Не для формы классов и типов и не для
реализации уже принятого решения.

1. Жесткие ограничения (физика, необратимое) - отдельно от предпочтений: сначала они отсекают варианты.
2. Действующие ADR и факты стека - силы, в которые решение обязано вписаться. Противоречие принятому -
   явный пересмотр (superseded), а не молча.
3. Найди ось, которая реально разводит варианты: онлайн против спящего клиента, кардинальность данных,
   владелец партиции против владельца сессии. Сравнение по осям, где все варианты равны, - шум.
4. Каждой альтернативе - сильнейшая форма и конкретный дисквалификатор, привязанный к силе ("O(N) на
   запрос"). Не можешь назвать дисквалификатор - вариант отвергнут рано. Лучший отвергнутый вариант
   оставь явно.
5. Часто лучшее - синтез: основа плюс доработка, а не пункт меню.
6. Цена честно: код и тесты, эксплуатация, новые инварианты, новые зависимости на горячем пути. Решение
   без минусов - реклама.
7. Обратимость: пока польза не доказана - обратимый вариант; необратимая ставка - с критериями go/no-go.
8. Путь миграции к следующей фазе и что блокирует что.

Уроки прошлых решений:
- Механизм в решении (повтор, перерезолв) требует предпосылку (идемпотентность) в том же решении, а не
  в открытых вопросах.
- На многошаговом синхронном пути - один бюджет дедлайна с передачей по шагам, а не свой таймаут на
  каждом шаге: иначе внешний шаг сдается, а внутренний оставляет осиротевшую операцию с эффектом.
- Различай "не дошло, можно повторить" и "могло дойти, повтор только при идемпотентности".
- Pub/Sub не заменяет адресный вызов, когда нужны резолв, гарантия доставки и корреляция.
- "Библиотека сделает сама" - проверить по ее модели: распределенная map с entry processor исполняет
  код на владельце партиции ключа, а не на узле с сессией клиента.
- Когнитивная нагрузка и bus factor - настоящий атрибут: сколько новых понятий сразу и потянет ли
  команда.

Результат - ADR скиллом `jkh:adr`: альтернативы с дисквалификаторами - в рассмотренные альтернативы;
цена, обратимость и путь миграции - в последствия. Нарезка принятого решения - скилл `jkh:epic`.
