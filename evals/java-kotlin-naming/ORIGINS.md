## Как применять примеры

- В Netty переименование последовательного чтения в `getByte` скрыло бы сдвиг позиции. Для нового
  API сначала выясни, есть ли такое различие; не копируй пару только из-за похожих типов.
- В coroutines `receiveCatching` возвращает закрытие канала через результат, но остается отменяемой
  suspend-операцией. Не выводи обещание "никогда не бросает" из одного суффикса.
- В Okio отсутствие завершающего перевода строки различает `readUtf8Line` и `readUtf8LineStrict`.
  Простого объяснения "nullable против non-null" недостаточно для полного контракта.
- В Android sample `completeTask(task, completed)` обрабатывает оба значения boolean. При ревью
  собственного аналогичного API полезен кандидат `setTaskCompleted`; это наша оценка читаемости,
  а не правило Android и не подтвержденный функциональный дефект библиотеки.
- При переносе идеи оставь терминологию своего домена. `Consumer`, `Mapper`, `Strategy` и `ViewModel`
  полезны только там, где обозначают действительную роль.

Эти примеры обосновывают решения. Они не задают словарь обязательных префиксов, список запрещенных
суффиксов или необходимость переименовывать стабильные API.
